## Guidelines

1. **Anonimize**: Remova nomes de clientes reais, IDs de contas, valores absolutos
2. **Formato**: PNG para prints, SVG para diagramas
3. **Tamanho**: Max 500KB por imagem (otimize com TinyPNG/Squoosh)
4. **Nomes**: kebab-case, descritivos
5. **Referência nos cases**: `![Alt text](/assets/images/case/file.png)`

## PDFs

Coloque relatórios em `assets/pdfs/` (ex: `relatorio-mensal-anonimizado.pdf`)
